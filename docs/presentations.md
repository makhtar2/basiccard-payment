# Presentations disponibles

Le projet contient maintenant deux versions de presentation.

## Version courte

Fichier :

```text
docs/presentation.pdf
```

Utilisation conseillee :

- presentation rapide ;
- resume du projet ;
- demonstration courte.

## Version detaillee

Fichier :

```text
docs/presentation-detaillee.pdf
```

Utilisation conseillee :

- soutenance plus longue ;
- explication etape par etape ;
- presentation devant un professeur ou un jury ;
- discussion technique sur la carte, le terminal, le protocole APDU, la compilation et la simulation.

La version detaillee explique :

- le contexte du projet ;
- le probleme traite ;
- les objectifs ;
- les technologies ;
- l'architecture ;
- les fichiers du projet ;
- la programmation de la carte ;
- la programmation du terminal ;
- le controle du PIN ;
- le blocage apres 3 erreurs ;
- le paiement ;
- le rechargement ;
- le ticket ;
- les fichiers `.zcc` et `.zct` ;
- la compilation ;
- le lancement de la simulation ;
- les tests ;
- les resultats ;
- les limites et les ameliorations possibles.
