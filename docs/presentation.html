Contexte du projet

Idee generale

Simuler un systeme de paiement par carte a puce avec BasicCard, un terminal et une monnaie locale : le FCFA.

Pourquoi ce sujet ?

Le projet montre comment une carte peut stocker un solde, verifier un PIN et valider une transaction.

Fonctionnalites

Paiement

Debit d'un montant en FCFA si le solde est suffisant.

Rechargement

Credit d'un montant positif sur la carte.

Securite

PIN obligatoire et blocage apres 3 mauvais codes.

Solde

Le solde est stocke dans la carte en EEPROM.

Ticket

Un ticket est affiche apres chaque paiement accepte.

Protocole APDU

CLAINSCommandeRole
8010GetBalance(PIN, Solde)Consulter le solde
8020Debit(PIN, Montant, Solde)Payer en FCFA
8030Credit(PIN, Montant, Solde)Recharger la carte

Codes retour

9000 succes, 6B01 solde insuffisant, 6B02 montant invalide, 6B03 PIN incorrect, 6B04 carte bloquee.

BasicCard FCFA7

Securite du PIN

Principe

  • Le PIN est verifie dans la carte.
  • Chaque erreur augmente un compteur.
  • A 3 erreurs, la carte se bloque.
  • Un PIN correct remet le compteur a zero.
If PinSaisi <> PinCode Then
    PinErrors = PinErrors + 1
    If PinErrors >= MaxPinErrors Then
        CarteBloquee = 1
        SW1SW2 = swCardBlocked
        Exit
    End If
End If

Limites et ameliorations

Limites actuelles

  • Pas de chiffrement des transactions.
  • Pas d'historique complet.
  • Pas d'identite client/commercant.
  • Pas de connexion bancaire reelle.

Ameliorations possibles

  • Code administrateur de deblocage.
  • Historique EEPROM.
  • Nom du client sur la carte.
  • Nom du commercant sur le ticket.
