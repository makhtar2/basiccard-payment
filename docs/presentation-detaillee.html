Contexte general

Paiement electronique

Dans un systeme de paiement, une carte peut representer un moyen simple de stocker une valeur et d'autoriser des transactions.

Adaptation locale

Le projet est adapte au Senegal : les montants sont exprimes directement en francs CFA, sans centimes.

Presentation detaillee3

Probleme traite

Question principale

Comment simuler un paiement par carte a puce, en protegeant l'acces avec un code PIN et en gerant un solde en FCFA ?

Stocker

La carte garde le solde meme apres une operation.

Verifier

Le PIN permet de s'assurer que l'utilisateur est autorise.

Transiger

Le terminal envoie des ordres de paiement ou de rechargement.

Etape 1 : programmer la carte

Responsabilites de la carte

  • Conserver le solde.
  • Conserver le PIN.
  • Verifier les autorisations.
  • Refuser les operations invalides.
Eeprom SoldeCompte As Long = 10000
Eeprom PinCode As Long = 1234
Eeprom PinErrors As Byte = 0
Eeprom CarteBloquee As Byte = 0

EEPROM : memoire persistante de la carte. Elle sert a garder les donnees importantes.

CommandeInstructionExplication

Credit80 30Ajouter un montant positif au solde.

Pourquoi des commandes ?

La carte ne donne pas directement acces a ses variables. Le terminal doit passer par des commandes controlees.

Presentation detaillee10

Etape 3 : verifier le PIN

Logique

  1. Le terminal envoie le PIN.
  2. La carte compare avec son PIN interne.
  3. Si le PIN est faux, elle renvoie une erreur.
  4. Si le PIN est correct, l'operation continue.
If PinSaisi <> PinCode Then
    SW1SW2 = swInvalidPIN
    Exit
End If
Presentation detaillee11

Etape 4 : bloquer apres 3 erreurs

But securitaire

Le blocage evite qu'une personne essaie plusieurs PIN jusqu'a trouver le bon.

Apres 3 erreurs, la carte renvoie le code 6B04.

If PinSaisi <> PinCode Then
    PinErrors = PinErrors + 1
    If PinErrors >= MaxPinErrors Then
        CarteBloquee = 1
        SW1SW2 = swCardBlocked
        Exit
    End If
End If
Presentation detaillee12

Etape 5 : effectuer un paiement

Conditions

  • La carte ne doit pas etre bloquee.
  • Le PIN doit etre correct.
  • Le montant doit etre positif.
  • Le solde doit etre suffisant.
If Montant > SoldeCompte Then
    SW1SW2 = swInsufficientFunds
    Exit
End If

SoldeCompte = SoldeCompte - Montant
NouveauSolde = SoldeCompte
Presentation detaillee13

Etape 6 : recharger la carte

Principe

Le rechargement ajoute un montant au solde. Dans ce projet, il est aussi protege par le PIN.

If Montant <= 0 Then
    SW1SW2 = swInvalidAmount
    Exit
End If

SoldeCompte = SoldeCompte + Montant
NouveauSolde = SoldeCompte

Dans un vrai systeme, le rechargement serait reserve a un terminal autorise ou a une banque.

Presentation detaillee23

Difficultes rencontrees

Port virtuel

Le terminal devait utiliser le port 201. Avec un mauvais port, le simulateur renvoyait une erreur de communication.

Reset de la carte

Il fallait appeler ResetCard apres la detection, sinon la carte etait presente mais pas initialisee.

Mode de lancement

Le simulateur doit recevoir la carte et le terminal ensemble pour que la carte soit inseree dans le lecteur virtuel.

Compilation

Le compilateur console utile est ZCMBasic.exe, tandis que certains outils ouvrent plutot une interface graphique.
